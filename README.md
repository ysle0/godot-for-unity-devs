# Godot for Unity Devs

Unity/C# 개발자를 위한 한국어 Godot 4.7 학습 사이트입니다. GDScript와 Godot의 핵심 구성요소, 워크플로를 Unity와 나란히 비교하며 설명합니다.

**상태**: 설계 단계(2026-09-28). 사이트와 Godot 프로젝트는 아직 없습니다.

## 문서

- [DESIGN.md](DESIGN.md): 사이트 계약. 독자, 범위, 커리큘럼, 챕터 템플릿, 검증 규칙, 첫 스파이크.
- [CONTEXT.md](CONTEXT.md): 용어집. 사이트 구성 단위와 Godot·Unity 용어 표기.
- [docs/adr/](docs/adr/): 되돌리기 어려운 결정과 그 이유.

문서와 사이트 본문은 한국어로 씁니다. 코드와 API 이름은 영어 원문을 씁니다.
