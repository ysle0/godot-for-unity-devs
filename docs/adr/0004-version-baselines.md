# 기준 버전: Godot 4.7.x, Unity 6.3 LTS

## Godot

- **고정 버전**: 사이트 내용은 Godot 4.7.x 기준으로 고정한다. `godot/` 아래의 Godot 프로젝트와 CI는 4.7.2를 쓴다.
- **최신을 따라가지 않는 이유**: 검증된 코드가 실제로 검증되려면 CI가 쓰는 엔진 버전과 본문이 말하는 버전이 같아야 한다.
- **다루지 않는 것**: Godot 3.x 내용은 다루지 않는다. API가 바뀐 곳만 짧게 표시한다.
- **4.8 대응 순서**:
  1. `godot/` 아래의 모든 Godot 프로젝트와 CI를 먼저 올려서 통과시킨다.
  2. 챕터를 하나씩 감사한다.
  3. 감사가 끝난 챕터부터 배지를 올린다.
  4. 그때까지 4.7 내용은 그대로 둔다.

## Unity

- **비교 기준**: Unity 6.3 LTS다.
- **다른 버전을 고르지 않은 이유**: 6.0 LTS는 2026년 10월에 지원이 끝난다. 6.6은 다음 릴리스가 나오면 교체되는 Supported 릴리스라서 비교 기준으로는 금방 낡는다.
- **6.7 LTS 대응**: 다음 LTS인 6.7이 나와도 기준을 바로 옮기지 않는다. 비교하는 개념(MonoBehaviour, Prefab, ScriptableObject)은 6.x 안에서 거의 변하지 않기 때문이다. 달라진 부분만 박스로 덧붙인다.
