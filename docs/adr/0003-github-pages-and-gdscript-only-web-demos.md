# GitHub Pages 호스팅과 GDScript 전용 단일 스레드 웹 데모

## 결정

- **호스팅**: 사이트는 공개 저장소의 GitHub Pages로 배포한다.
- **데모 형태**: 웹 데모는 단일 스레드로 내보낸 GDScript 프로젝트로만 만든다.
- **데모 위치**: 모듈 끝의 샘플 단계 페이지에만 둔다. 독자가 눌러야 로드하고, 페이지당 하나만 둔다.

## 코드에서 보이지 않는 제약

- **Godot C# 웹 내보내기 불가**: Godot 4.7의 .NET 빌드는 Web 내보내기 검증에서 항상 실패한다. 공식 문서도 Godot C# 프로젝트는 Web으로 내보낼 수 없다고 적는다. 관련 PR(#106125, #118976)은 2026-09-28 기준 초안이다.
- **wasm 용량**: 공식 4.7.1 웹 템플릿의 `index.wasm`은 37.7 MiB다. Cloudflare Pages/Workers의 파일당 25 MiB 제한을 넘는다. GitHub Pages는 이 파일을 gzip으로 약 9.8 MiB(10,248,573 B)에 제공한다.
- **헤더 없이 동작**: 단일 스레드 내보내기는 COOP/COEP 헤더 없이 HTTPS만 있으면 된다. 공식 데모가 GitHub Pages에서 그렇게 실행되는 것을 2026-09-28에 직접 확인했다.
- **무거운 첫 로드**: 첫 로드가 약 10 MB다. 그래서 데모를 개념 챕터마다 넣지 않고 페이지당 하나로 제한한다.

## Considered Options

- **Cloudflare Pages/Workers**: 커스텀 헤더를 지원해서 멀티 스레드 내보내기도 가능하다. 하지만 wasm을 R2 같은 별도 저장소로 분리해야 한다.
- **Netlify/Vercel**: 헤더 설정은 가능하다. 하지만 GitHub Pages보다 나은 점이 이 사이트에는 없다.
- **데모 없이 스크린샷만**: 가장 가볍다. 하지만 Unity 사용자가 "실제로 이렇게 움직인다"를 확인할 수단이 사라진다.
- **개념 챕터마다 데모**: 페이지마다 약 10 MB를 내려받게 된다.
